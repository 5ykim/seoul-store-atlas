## 제출 준비 완료

- [x] Cloudflare 앱을 로그인 없이 공개 접속할 수 있음(HTTP 200).
- [x] 425개 행정동과 2025년 1~4분기 데이터가 제공됨.
- [x] 지도 클릭·산점도 선택·분기·자치구 필터·모바일 화면을 브라우저에서 점검함.
- [x] 분석표(CSV)와 분석 보고서 내려받기가 정상 작동함.
- [x] 공개 GitHub 저장소에 앱 코드·분석 코드·원본 공개자료·대표 이미지가 올라감.
- [x] 분석 노트북의 코드 셀 8개를 실행해 표와 지도·산점도 출력을 저장함. 오류 출력 없음.
- [x] 데이터 연결·합계·Density·Entropy·LQ의 재계산 검증 6개 항목 통과.
- [x] 연구 질문·자료 출처·전처리·계산식·지역 차이·해석과 한계를 앱과 보고서에 작성함.
- [x] 공개 자료는 행정동×업종 집계 자료이며, 개인 단위 자료를 포함하지 않음.
- [x] API 키가 필요 없는 정적 앱이며, 인증 파일·임시 파일은 Git 추적 대상에서 제외됨.
- [x] 대표 이미지와 노션 입력용 문구를 준비함.
